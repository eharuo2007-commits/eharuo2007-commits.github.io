                PROJETO 01
                LOGISTICS & SURGE PRICING ENGINE
              

              

                ● v2.4 PROD
                ✓ 100% Automated Tests
              

            


            

              
              

                

                  LogiEngine AI — Motor de Precificação Dinâmica, Roteirização e SLA Logístico
                

                

                  Microsserviço híbrido de última milha que combina cálculo geográfico determinístico por CEP (fórmula de Haversine + fator viário 1.34x e tarifação R$ 1,80/km) com inferência preditiva via Google Gemini API (response_format JSON Schema). Calcula Surge Pricing (1.0x a 2.5x), SLA dinâmico e recomendação de despacho com fallback resiliente e persistência em IndexedDB/SQL (tb_logistics_quotations).
                


                

                  

                    
01 // Problema de Escala

                    

                      Motores estáticos de frete baseados apenas em distância linear falham em operações reais de alta frequência quando ocorrem tempestades severas, retenções arteriais e desequilíbrio agudo entre oferta e demanda de entregadores.
                    

                  


                  

                    
02 // Arquitetura Neuro-Simbólica

                    

                      A camada determinística (pricingEngine.js) calcula a geodésica Haversine com correção viária (1.34x) e tarifa base (R$ 4,50 + R$ 1,80/km), enquanto o modelo gemini-3.8-flash infere surge_multiplier, estimated_sla_minutes e alocação de modal sob JSON Schema estrito.
                    

                  


                  

                    
03 // Destaques de Engenharia

                    

                      Degradação graciosa com motor determinístico offline instantâneo, benchmark A/B em tempo real (Estático vs IA), telemetria persistida na tabela tb_logistics_quotations (IndexedDB/SQL) e suíte via Node Test Runner.

                PROJETO 02
                FINOPS, CYBERSECURITY & ANTI-FRAUD
              

              

                ● v2.4 PROD
                ✓ 100% Automated Tests
              

            


            

              
              

                

                  FinGuard AI — Conciliação Financeira, PII Masking (LGPD) e Detecção de Fraudes
                

                

                  Gateway Zero-Trust de auditoria financeira para plataformas de delivery. Sanitiza dados sensíveis em tempo real (CPF, e-mail, PAN de cartão via PCI-DSS truncation e hashes FNV-1a anti-Sybil) antes da chamada ao LLM. Combina 4 políticas determinísticas (<1ms para estornos duplicados no mesmo minuto e abuso de cupons) com análise preditiva via Gemini API, Retry Pattern com Exponential Backoff + Jitter e banco local tb_finops_audit_logs.
                


                

                  

                    
01 // Problema de Escala

                    

                      Auditar milhares de solicitações de reembolso, cupons promocionais e repasses a restaurantes exige prevenção instantânea contra ataques Sybil/Replay sem jamais expor dados pessoais brutos (LGPD Art. 46 / PCI-DSS) para APIs externas de IA.
                    

                  


                  

                    
02 // Arquitetura Neuro-Simbólica

                    

                      O módulo piiMasker.js mascara CPF/E-mail/PAN preservando correlação via hashes determinísticos FNV-1a; deterministicRules.js intercepta duplicidades no mesmo minuto (<1ms) e o Gemini classifica anomalias sob contrato estrito.
                    

                  


                  

                    
03 // Destaques de Engenharia

                    

                      Gatekeeper verifyZeroPIIExposure() com bloqueio imediato de vazamento, resiliência de rede via retryWithBackoff.js (Exponential Backoff + Full Jitter) e exportação de auditoria SQL (tb_finops_audit_logs).

                PROJETO 03
                MULTI-AGENT ORCHESTRATION & RAG
              

              

                ● v2.4 PROD
                ✓ 100% Automated Tests
              

            


            

              
              

                

                  Nexus Orchestrator — Plataforma Multi-Agente com RAG e Roteamento Semântico
                

                

                  Orquestrador omnichannel que classifica intenções de usuários e parceiros via Semantic Router (SUPPORT_LOGISTICS, FINOPS_DISPUTES, API_INTEGRATION), recupera políticas técnicas de uma base de conhecimento documental (RAG) para mitigar alucinações com citação de fontes e fornece painel Split-View de observabilidade com inspeção de tokens, latência e guardrails.
                


                

                  

                    
01 // Problema de Escala

                    

                      Atendimentos críticos de restaurantes parceiros, entregadores e desenvolvedores sofrem com alucinações de políticas operacionais quando enviados a um único prompt monolítico sem isolamento de contexto e sem aterramento documental.
                    

                  


                  

                    
02 // Arquitetura Neuro-Simbólica

                    

                      O semanticRouter.ts calcula probabilidades via distribuição Softmax calibrada ($T=2.8$) para acionar o sub-agente especialista correto (Atlas, Ledger ou Pulse), injetando os topK = 3 manuais recuperados pelo motor RAG (ragService.ts).
                    

                  


                  

                    
03 // Destaques de Engenharia

                    

                      Citação estrita de documentos (DOC-LOG-101, DOC-FIN-201, DOC-API-301), painel Raio-X Split-View com telemetria de latência por estágio, contagem de tokens/custo e persistência em tb_nexus_orchestrator_logs.
